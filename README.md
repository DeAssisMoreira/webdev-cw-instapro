# Instapro

MVP социальной сети для обмена фотографиями

Верстка списков постов с API;
Реализована функция выкладывать изображение с возможностью его текстового описания;
Сделана страница отдельного пользователя, на которой можно просматривать конкретно его посты;
Возможность поставить лайк или деактивировать его.

## Первоначальная оценка

10 часов

## Фактически затраченное время

~25 часов
